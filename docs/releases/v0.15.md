# PORT v0.15 release notes

## v0.15.0

*Prepared 2026-10-31, not yet tagged.* A minor release of the two npm packages that share one version (`@valancex/port-web`, `@valancex/port-desktop-vocabulary`). The Desktop PORT crate is unchanged (`valancex-port-desktop` 0.6.0). **It needs MESH 0.18.0 for `composeWebPort`'s context and the screen (`openScreen`).** All additions are additive and **Provisional**; the full text is in the [changelog](../../CHANGELOG.md#0150---2026-10-31-prepared-not-yet-released-the-crate-stays-060).

### `@valancex/port-web` 0.15.0

- **`composeWebPort`** (Tier 1, Provisional): drives a Web PORT from a Mesh `screen`; `show(snapshot)` draws then patches, interactions go through the screen to `onIntent`, `close()` empties the container. `onError` is optional. The screen is typed structurally, so the module imports nothing from Mesh at run time.
- **`show(snapshot, context?)`** (Tier 1, Provisional): the context goes to the screen's `show` (MESH 0.18), so a context-only change patches in place. Needs MESH 0.18.0.
- **`@valancex/port-web/vocabulary`** (Tier 1, opt-in, Provisional): `vocabulary` (the portable core as a `WebPrimitives` table) and `vocabularyManifest`. Not a default; `primitives` stays required.
- **The native hatch** (Tier 3, Provisional, Web only, not in contract version 1): `createWebPort`'s `native`, typed from `@valancex/port-web/native`, a primitive's `opaque`, and the code `opaque-children`.
- **The MESH runtime peer range admits 0.18.0** (`… || ^0.17.0 || ^0.18.0`). `test/architecture.test.ts` pins lines 6 through 18.
- **Audits** (Valance `docs/NORTH_STAR_SCORECARD.md`): **E2** ◐ → P; **T1.2** stays ◐ (C-2: the vocabulary is opt-in) and, for the helper, a required `onError` became optional; **H1** F → P; **H2** – → P.

### `@valancex/port-desktop-vocabulary` 0.15.0

Version only (the two packages share one). No change.

Breaking? No. **Tiers:** Tier 1 (`composeWebPort`, `show` context, `./vocabulary`), Tier 3 (the native hatch); all Provisional.

### Release steps (the maintainer's)

1. Publish MESH 0.18.0 to npm first.
2. Revert d9f28ed and 2d65e20 (the local packs), and point port-web's `@valancex/mesh-compiler` and `@valancex/mesh-runtime` devDependencies at the registry `^0.18.0`; run `pnpm install`.
3. Run `node scripts/check-mesh-range.mjs` and the tests.
4. Merge when CI is green; tag `v0.15.0` (npm, `release.yml`). The crate is not released.
5. In Valance, raise `@valancex/port-web` and `@valancex/port-desktop-vocabulary` to `^0.15.0`.
