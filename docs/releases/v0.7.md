# PORT v0.7 release notes

## v0.7.0

*Prepared 2026-10-16 (nothing tagged or published: v0.6.1 is the latest release).* A minor release of the two packages that share one version and are published together: `@valancex/port-web` and `@valancex/port-desktop-vocabulary`.

### `@valancex/port-desktop-vocabulary` 0.7.0

The Desktop PORT's vocabulary grows, **additively**: every prop below is optional unless it belongs to a new component, so a template written against 0.6 compiles and draws as before.

- **Form primitives**, the names and types the Web PORT's tag table already has for a Valance application: `kind` on `textfield` (`password` masks), `invalid` and `describedby` on `textfield` and `checkbox`, `id` on `text` and `paragraph`, and the events `focus` and `blur` on `textfield`.
- **A choice group**: `radiogroup` (`label`, `invalid`, `describedby`; no events) and `radio` (`checked` and `value`, required; `label`, `disabled`), which raises the new event `select` with its `value`. The event verbs are now seven: `click`, `change`, `submit`, `cancel`, `focus`, `blur`, `select`.

The design notes are in the Valance repository: `docs/application-model/FORM-PRIMITIVES.md` and `docs/application-model/CHOICE-GROUP.md`. The tools that check a template read the vocabulary from this package, so after this release the Valance CLI raises its range to `^0.7.0` and a two-target project may write these props for the desktop.

### `@valancex/port-web` 0.7.0

No change to its API, behavior or peer range. It moves to 0.7.0 so the workspace has one version, and one `v0.7.0` tag publishes both packages.

### The Desktop PORT crate

`valancex-port-desktop` is released on its own tag, `desktop-v0.1.0`; its first release carries the same vocabulary, drawn by the window, and one host message more: **`resize`** (the width of the window's content in whole points), so the application can tell a narrow window from a wide one. Nothing in the crate is released yet (see its [changelog entry](../../CHANGELOG.md)).

### Release steps (the maintainer's)

In the Valance repository, raise `@valancex/port-desktop-vocabulary` to `^0.7.0`.
