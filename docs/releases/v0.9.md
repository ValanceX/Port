# PORT v0.9 release notes

## v0.9.0

*Prepared 2026-10-17.* A minor release of the two npm packages that share one version and are published together: `@valancex/port-web` and `@valancex/port-desktop-vocabulary`. The Desktop PORT crate is released on its own tag (`desktop-v0.3.0`).

### `@valancex/port-desktop-vocabulary` 0.9.0

The Desktop PORT's vocabulary grows by seven components, **additively**: a template written against 0.8 compiles and draws as before. The vocabulary is seventeen components.

- **A static table**, the design in the Valance repository's `docs/application-model/TABLE.md` (RF-12): `table` (`label`), `tablehead` and `tablebody` (its header rows and its data rows), `tablerow`, `columnheader` (`sort`: `ascending`, `descending`, `none` or `other`), `rowheader` and `cell`. No events. The name `tablerow` is because `row` is already a layout component.
- It is **static**, on purpose: no selection, editing or arrow-key navigation inside it. Sorting and the layout at a narrow width are the application's (a sortable header holds a `button`; the layout reads `viewport` and chooses a table or a list). A table of controls is a separate decision, made when an application needs one.

### `@valancex/port-web` 0.9.0

No change to its API, behavior or peer range. It moves to 0.9.0 so the workspace has one version, and one `v0.9.0` tag publishes both packages.

### The Desktop PORT crate, 0.3.0

`valancex-port-desktop` 0.3.0 draws the table as one grid, the header rows strong and each cell's content inline. It sets in the accessibility tree what the toolkit's grid does not: a `Table` (with its name and row and column counts), `Row`s (with their index), `Cell`, `ColumnHeader` and `RowHeader` (with their row and column indices; `sort` becomes the sort direction). Headless tests read the tree back. A real window was not driven for the table.

### Release steps (the maintainer's)

1. Merge this change when CI is green. 2. Tag the merge commit `v0.9.0` (publishes the two npm packages, `release.yml`) and `desktop-v0.3.0` (publishes the crate and the prebuilt `vlx-window`, `release-desktop.yml`). 3. In the Valance repository, raise `@valancex/port-desktop-vocabulary` and `@valancex/port-web` to `^0.9.0`, delete the checkout-based table test in `cli/test/table.test.ts` (and the test that says the installed vocabulary has no table) and add the seven names to the parity test in `cli/test/choice-group.test.ts`.
