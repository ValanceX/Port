# PORT v0.8 release notes

## v0.8.0

*Released 2026-10-16 (`v0.8.0`; the crate, `desktop-v0.2.0`, on 2026-10-17).* A minor release of the two npm packages that share one version and are published together: `@valancex/port-web` and `@valancex/port-desktop-vocabulary`. The Desktop PORT crate is released on its own tag (`desktop-v0.2.0`).

### `@valancex/port-desktop-vocabulary` 0.8.0

The Desktop PORT's vocabulary grows by one component, **additively**: a template written against 0.7 compiles and draws as before.

- **`label`**: holds a control and the text that names it. No props, no events. The text written directly inside is the control's visible text and accessible name; the first control inside (`checkbox`, `radio` or `textfield`) is the one named, and a click on the text does what a click on the control does. The vocabulary is ten components. The design is in the Valance repository, `docs/application-model/CHOICE-GROUP.md` (WA-14).

### `@valancex/port-web` 0.8.0

No change to its API, behavior or peer range. It moves to 0.8.0 so the workspace has one version, and one `v0.8.0` tag publishes both packages.

### The Desktop PORT crate, 0.2.0

`valancex-port-desktop` 0.2.0 draws `label`: a checkbox or radio shows the text beside the box, a text field shows it before the field and takes the cursor when the text is clicked, and the text is the control's name in the accessibility tree.

### Release steps (the maintainer's)

1. Merge this change when CI is green. 2. Tag the merge commit `v0.8.0` (publishes the two npm packages, `release.yml`) and `desktop-v0.2.0` (publishes the crate and the prebuilt `vlx-window`, `release-desktop.yml`). 3. In the Valance repository, raise `@valancex/port-desktop-vocabulary` to `^0.8.0` and drop the checkout-based parity check for `label`.
